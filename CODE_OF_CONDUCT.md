# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) by reference. Read the full text at that link. It applies in all project spaces, including issues, pull requests and discussions, and when someone represents the project in public.

## Summary

- Be kind and respectful. Welcome people of every background and experience level.
- Give and accept feedback on the work, not the person.
- No harassment, insults, discrimination or unwelcome sexual attention.
- Do not publish other people's private information.
- Own your mistakes and learn from them.

## Reporting

To report a problem, use one of these:

- Open a private [security advisory](https://github.com/anake-an/atap/security/advisories/new) and say it is a conduct report.
- Report the comment, issue or pull request to GitHub.

Please do not report conduct problems in public issues. The maintainer is Aniq Najmuddin ([@anake-an](https://github.com/anake-an)). All reports are treated with care and kept private. If your report is about the maintainer, report the content to GitHub.

## Enforcement

The maintainer decides how to respond, following the [Contributor Covenant enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines). That can mean a correction, a warning, a temporary ban or a permanent ban.
