### Added

- Edit layout: choose what the notch shows when idle, when you point at it, and on each panel page. It opens from the notch menu, from Settings, or from the command bar.
- Add widgets from a list you can search. A widget that cannot go in a spot says so.
- Pick a size for each widget (S, M or L, where it has more than one), move it up or down, or remove it.
- Add or remove panel pages, up to six.
- Compact priority: when two things are live at once, choose which one gets the small notch.
- Undo and Redo, Start over, and Cancel. Nothing is saved until you press Done, and then it is saved in one go.
- Settings can bring back the layout from before the last time you pressed Done.
- If the layout file changes outside Atap while you edit, the editor offers to reload it rather than overwrite it.
- While you edit, the notch shows a small "Editing layout" badge.
