### Changed

- Everything Atap does later or on repeat now shares one timer. Updates that are due close together run in the same wake, so the PC wakes less often. With the default layout Atap still wakes only once a minute, for the clock.
- On battery saver, background updates run four times less often, and they return to their normal pace as soon as saver turns off. Times you set yourself are never delayed.
- After the PC wakes from sleep, updates that were missed run once, together, within about a minute, instead of waiting for their next turn.

### Fixed

- A setting changed just before the PC went to sleep is now applied when it wakes. Before, it could be lost until the next change.
