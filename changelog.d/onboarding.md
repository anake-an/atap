### Added

- First-run setup on a new install: pick a language, where the notch sits, and a starting layout. Then your area if you picked Malaysia, and whether Atap starts with Windows.
- Language and position change right away, so you see the result while you choose.
- Four starting layouts: Minimal, Student, Work and Malaysia. Each says whether it uses the internet. You can change everything later with Edit layout.
- Skip setup keeps everything as it is. Setup never shows again, and people upgrading from an earlier Atap never see it.
