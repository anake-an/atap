### Added

- A shared set of controls for the coming widgets: round icon buttons, thin progress bars, status dots and widget cards. Nothing shows in the app yet.
- More than 50 line icons for media, time, system, weather and everyday actions.
- Views for the custom widgets' values: Number, Text, Progress, List and Status dot. Warning values show in amber and critical ones in rose, each with a dot, so colour is never the only sign.
- When a custom widget has no value, it says why in plain words, such as "This value is not a number". The last good value is marked "Out of date" after a failed refresh.
- Every new control has a screen reader name, shows a focus ring when you use the keyboard, and grows with the text size.
- In Windows high contrast mode the controls use your system colours, and status dots also change shape for each level.
- None of the new controls move or animate on their own, so the notch stays idle.
